Privacidad

Política de privacidad

Este documento resume el tratamiento básico de los datos enviados desde formularios y canales de contacto del sitio para responder solicitudes comerciales.

Responsable del tratamiento

Transportes Santa Fe del Norte recibe y procesa los datos enviados por el usuario mediante formularios y canales de contacto directos del sitio.

Correo comercial: Completar correo comercial

Base operativa: Completar dirección o base operativa

Datos que se recopilan

  • Nombre y empresa.
  • Cargo, teléfono y correo electrónico.
  • Tipo de servicio requerido.
  • Mensaje con detalles del requerimiento.

Finalidad de uso

Los datos se utilizan únicamente para responder consultas comerciales, coordinar requerimientos de servicio y realizar seguimiento asociado a la solicitud recibida.

No se deben usar para campañas no relacionadas sin autorización del titular.

Conservación y seguridad

La información debe mantenerse solo por el tiempo necesario para gestionar la solicitud y cumplir obligaciones comerciales o administrativas aplicables.

Se recomienda revisar el proveedor del formulario una vez que se reemplace {{FORM_ENDPOINT}} para asegurar almacenamiento y envío adecuados.

Contacto para dudas

Si necesitas actualizar o eliminar información enviada desde este sitio, utiliza el correo o teléfono comercial oficial una vez configurados.
